# Phonebook MERN

A full-stack phonebook application built with the MERN stack.

## Tech Stack

- React
- Node.js
- Express
- MongoDB Atlas
- Mongoose
- Render

## Features

- Create contacts
- View contacts
- Update contacts
- Delete contacts
- REST API
- Production deployment
